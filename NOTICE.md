# Third-party material notice

This repository is a **diagnostic reproduction snapshot**. It is not a Jieli SDK
distribution and is not affiliated with or endorsed by Jieli Technology (杰理科技).

## Our own material

`patches/`, `tools/`, `sdk-diff/sdk-changes.patch`, `hello-flash/app.bin`,
`hello-flash/flash_hello.bat`, `history/`, `logs/`, `artifacts/sdk.elf` and all `*.md`
documents were produced in this project. The SDK source modifications are 69 lines of
`git diff` plus one new 26-line C file.

## Vendored third-party binaries (included only for exact reproduction)

`hello-flash/` contains files copied **unmodified** from:

- Jieli's public SDK `cpu/br23/tools/` and `cpu/br23/tools/download/standard/`
  (`isd_download.exe`, `uboot.boot`, `br23loader.bin`, `key.txt`, `tone.cfg`,
  `cfg_tool.bin`, `eq_cfg_hw.bin`, `isd_config.ini`, `ota.bin`, `font.bin`,
  `gbk2utf8.tab`, `script.ver`)
- the lztttt tool pack (`workspace/lztttt/firmware/`), which in turn carries the same
  SDK files (verified byte-identical)
- `jl_isd.bin` / `jl_isd.fw` generated by `isd_download.exe` during the flash

These are proprietary to their respective owners and are provided here **only** so a
third party can reproduce the exact failing flash byte-for-byte. If redistribution is a
concern, delete `hello-flash/` and fetch the same files from the upstream SDK;
[`tools/bootstrap.py`](tools/bootstrap.py) and [`FLASH.md`](FLASH.md) document how.
Hashes for every file are in [`MANIFEST.sha256`](MANIFEST.sha256) so a reviewer can
verify equivalence without trusting this copy.

The 289 MB SDK tree itself is **not** included — it is cloned at a pinned commit from
`https://gitlab.zh-jieli.com/soundbox/novisualization/ac695n_soundbox_sdk.git`.

The known-good "Asuka v0.9.177" package is **not** vendored; only its hashes, file sizes
and flash command are quoted in [`EVIDENCE.md`](EVIDENCE.md) for comparison.

## Warning

`hello-flash/` is the package that produced a non-enumerating device. Do not flash it
onto hardware you cannot recover with a USB_KEY dongle or a full-chip backup.
See [`REPRODUCE.md`](REPRODUCE.md#safety--recovery).
